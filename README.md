# Porta a Porta — React Native + TypeScript

MVP mobile baseado nos protótipos do projeto, incluindo a tela “Meus pedidos”.

## Executar
1. Instale Node.js.
2. Abra esta pasta no VS Code.
3. No terminal:
   npm install
4. Depois:
   npx expo start
5. Instale o Expo Go no celular e escaneie o QR Code.

O MVP demonstra vitrine, busca, carrinho, finalização, pedidos, status, avaliação, peça de novo e perfil.

Observação: esta versão não possui banco de dados, API ou autenticação real. Os dados ficam somente durante a execução.
